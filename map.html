Usage help

🎯 Working with notes

➕ Right-click on the image to add a marker

Click on a marker — opens the chat panel with messages

Right-click on a marker to edit it or choose a new position

📋 List — shows all markers

📖 General — opens a panel to edit general information about the image

🖱️ Image controls

Mouse wheel — zoom

Click and drag — pan the image

Zoom buttons — zoom in / out / reset

📁 Working with files

Upload image — pick a file from your device, it is stored on the server

Or insert an image by URL — it stays at the source you provide and is shown in original quality, without compression

Uploaded files have a total storage limit of 50 MB per account — that's why linking by URL helps save space

💾 Data storage

All data is saved on the server — nothing is stored only in the browser

Sign in from any device and your notes, markers and images will be there
